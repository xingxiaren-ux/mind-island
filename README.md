# 心靈島 Mind Island

3D 社會情緒學習（SEL）互動小島。用瀏覽器開啟 `index.html` 即可（需連網載入 three.js）。

## 內容
- 五個區域對應 CASEL 五大 SEL 能力：情緒灣、平靜山、共感村、橋樑港、抉擇森林
- 三種角色：患者（垂耳兔）、引導者（小鹿）、解決問題者（小熊）
- 點擊村民會出現 SEL 小情境，不同角色看到不同的選項與回饋
- 日夜循環、輪船、小魚、魔幻森林

## 操作
- 按住拖曳旋轉，滾輪或雙指縮放
- 點擊地點標籤飛到區域，點擊村民頭上的 💭 開始對話

## 上傳到 GitHub Pages
1. 在 GitHub 建立公開倉庫（例如 mind-island）
2. 上傳 `index.html` 和 `README.md`
3. Settings → Pages → Deploy from a branch → main / (root)

本工具為情緒學習活動，不是診斷或治療。若現實中你或身邊的人正感到難受，請告訴信任的大人、老師或專業協助單位。
