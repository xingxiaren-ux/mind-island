# SEL 成長島 Mind Island

3D 社會情緒學習（SEL）互動小島。用瀏覽器開啟 `index.html` 即可（需連網載入 three.js）。

## 內容
- 九個區域：情緒灣、平靜峰、共感村、橋樑港、抉擇森林、迴音谷、願景塔、雙贏城堡、成長園
- 三種角色：患者（垂耳兔）、引導者（小鹿）、解決問題者（小熊），可自由行走，從橋樑港出發
- 情緒灣：標記現在的心情，領取「情緒信物」（帽子），並建議你該去哪個區域
- 成長園：把任務變成養分，從種子養成大樹
- 玩法：後果鏡子、善行徽章、暴風雨襲擊橋樑港的團隊事件
- 任務指引：箭頭與光柱帶你前往下一個地點
- 完成任務會在角色頭頂放煙火（可關閉）；所有彈出介面都有 ✕ 關閉鍵（也可按 Esc）

## 操作
- 電腦：WASD／方向鍵移動，拖曳轉視角，滾輪縮放，E 互動
- 手機：左下角搖桿移動，雙指縮放，單指拖曳轉視角
- 點地面或區域牌子，角色會自動走過去

本工具為情緒學習活動，不是診斷或治療。若現實中你或身邊的人正感到難受，請告訴信任的大人、老師或專業協助單位。
